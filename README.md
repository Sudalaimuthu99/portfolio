# Sudalaimuthu Portfolio

This is a cinematic embedded systems portfolio built with HTML, CSS, and JavaScript.

## Open in VS Code
1. Open VS Code.
2. Choose `File > Open Folder...`.
3. Select `C:\portfolio`.
4. Open `index.html`.
5. Start Live Server or use a local HTTP server.

## Run with Python
```powershell
cd C:\portfolio
python -m http.server 8000
```
Then open:
```text
http://localhost:8000
```

## Run with Live Server
- Install the VS Code Live Server extension.
- Open `index.html`.
- Click `Go Live` in the status bar.

## Files
- `index.html` — page markup
- `style.css` — page styles
- `script.js` — 3D animation and effects
- `assets/resume/Sudalaimuthu_Resume.pdf` — resume download target
- `assets/images/` — SVG placeholders
